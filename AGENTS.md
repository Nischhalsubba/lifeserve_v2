# Repository Instructions

## Setup

LifeServe V2 is a static HTML, CSS, JavaScript, and Bootstrap website.

```bash
python -m http.server 8000
```

## Content rules

- Verify the organization, mission, services, programs, events, contact details, volunteer opportunities, and donation information.
- Keep dated news and event content current or clearly archived.
- Do not use invented impact metrics, testimonials, beneficiaries, or partner logos.
- Keep emergency or support information accurate and easy to find.

## Action rules

- Clearly distinguish contact, volunteer application, donation, and newsletter actions.
- Do not collect personal or payment data without a verified backend and privacy policy.
- Donation links must point to an approved secure provider.
- Confirm form delivery and user confirmation states.

## Verification

1. Open every HTML page and check assets.
2. Test navigation, forms, donation, volunteer, and contact links.
3. Review mobile layouts and Bootstrap behavior.
4. Check keyboard access, focus, contrast, labels, and alt text.
5. Verify organization facts and all dated content.
6. Add and validate metadata before deployment.

## Do not

- Do not publish stale service or event information.
- Do not imply donation processing works without verification.
- Do not expose sensitive form submissions through static frontend code.
- Do not present the repository thumbnail as a runtime screenshot.
